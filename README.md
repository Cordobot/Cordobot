# 📱 Adrián Alvarez — Android Developer
I'm Adrián Alvarez, a Software Engineer specialized in native Android app development. 
I'm passionate about building efficient, scalable apps with great user experience using 
the modern Android ecosystem.

My main stack is Kotlin + Jetpack Compose, applying solid architectures like MVVM and 
Clean Architecture, with local data management using Room, REST API consumption with 
Retrofit, dependency injection with Hilt, and async programming with Coroutines and Flow.

What sets me apart: I combine technical solid foundation with product vision — I don't 
just write code, I design solutions with the end user in mind.
